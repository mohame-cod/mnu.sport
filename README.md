# التسجيل الرياضي الجامعي — Frontend Only

## الملفات
`index.html` تسجيل الطلاب · `admin.html` لوحة الإدارة · `styles.css` التصميم · `common.js` بيانات ودوال مشتركة · `app.js` منطق التسجيل · `admin.js` الحماية والإحصائيات والتصدير · `assets/lib/xlsx.full.min.js` مكتبة Excel محلية (لا تحتاج إنترنت).

## التشغيل
1. فك الضغط وافتح `index.html` للتسجيل و`admin.html` للإدارة (في نفس المتصفح والجهاز).
2. أول دخول للوحة الإدارة: اختار كلمة مرور (10 أحرف على الأقل). لو نسيتها مفيش استرجاع؛ الحل الوحيد مسح بيانات الموقع من المتصفح، وده بيمسح التسجيلات كمان، فصدّر Excel بشكل دوري.

## تصدير Excel
- ملف مستقل لكل لعبة: `كرة_القدم.xlsx`، `كرة_الطائرة.xlsx`، `كرة_اليد.xlsx`، `كرة_السلة.xlsx`، `تنس_الطاولة.xlsx`، `السباحة.xlsx`، `ألعاب_القوى.xlsx`، `البادل.xlsx`.
- `بنين.xlsx` للبنين فقط و`بنات.xlsx` للبنات فقط (مع أعداد كل لعبة في أعلى الملف).
- `جميع_التسجيلات.xlsx`: ورقة لكل الطلاب وورقة للبنين وورقة للبنات وورقة لكل لعبة.
- أعلى كل ملف: اسم الجامعة، العنوان، اسم اللعبة/النوع، التاريخ، الإحصائيات، ثم الجدول. أسماء الملفات بدون بيانات شخصية. القيم اللي تبدأ بـ `= + - @` بتتحول لنص لمنع حقن الصيغ في Excel.

## الحماية المطبقة
- كلمة مرور للوحة الإدارة (تُخزَّن كـ PBKDF2-SHA256 مع salt، وليست نصًا).
- قفل 5 دقائق بعد 5 محاولات خاطئة، وانتهاء الجلسة بعد 15 دقيقة خمول، وزر تسجيل خروج.
- اللوحة لا تُرسم قبل تسجيل الدخول، والرقم القومي والهاتف مخفيين بالنجوم ويظهران بزر لكل طالب.
- عرض كل البيانات بـ `textContent`، وCSP تمنع السكربتات الخارجية، وتحقق صارم من المدخلات.

## حدود الحماية (مهم)
هذه حماية على مستوى الواجهة فقط وليست حماية حقيقية. البيانات وهاش كلمة المرور في LocalStorage، وأي شخص عنده وصول للجهاز وأدوات المطور يقدر يقرأ البيانات أو يمسح الحماية. البيانات لا تتزامن بين الأجهزة، وتُفقد بمسح بيانات المتصفح. لا تستخدم هذه النسخة لجمع بيانات طلاب حقيقيين من أجهزة مختلفة؛ ده يحتاج سيرفر وقاعدة بيانات وتسجيل دخول من الخادم.
